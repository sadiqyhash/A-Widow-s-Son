# A Widow's Son — 8-Work WebAR

This package contains the working 8-work MindAR experience and the revised landing page.

## Landing page
The landing page is intentionally minimal and black. The sequence is:

**A Widow’s Son**

[Supplied landing image, centered near the top]

**Point your camera at the artwork to reveal what is hidden.**

**Enter**

The supplied `assets/landing.png` is used as provided. The landing artwork is not cropped or modified.

After tapping **Enter**, the camera-access screen appears. Starting the camera launches the existing 8-work AR experience.

## AR
- 8 artwork targets
- 8 matching solution overlays
- Existing target mapping and alignment setup preserved
- `?debug=1` remains available for alignment testing

Deploy the contents of this folder to an HTTPS host such as Netlify.
